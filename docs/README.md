# Документация

Начните с [корневого README](../README.md): задача, стек, безопасный пример,
подтверждённые метрики и quick start для локального API/Docker Compose.

- [Архитектура](architecture.md) — этапы, ветвление, retrieval и валидация.
- [Эксплуатация](operations.md) — импорт, CLI, API и хранение данных.
- [Docker](docker.md) — запуск и диагностика readiness.
- [Evaluation](evaluation.md) — сохранённые результаты и ограничения сравнения.
- [Состояние проекта](project-status.md) — возможности и открытые ограничения.
- [Проверки оформления](verification.md) — выполненные проверки и оставшиеся ошибки.
- [Roadmap](roadmap.md) — дальнейшие исследовательские и инженерные задачи.
- [OCR lab](../tools/ocr_lab/README.md) — текущий OCR и прежние исследования.
- [Evaluation tools](../tools/evaluation/README.md) — сборщики приватных датасетов.

Публичные результаты в `results/` содержат только агрегированные JSON-отчёты.
Старые подробные отчёты с пересказами реальных обращений остаются локальными
игнорируемыми файлами.
