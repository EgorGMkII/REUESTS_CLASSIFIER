# Состояние проекта

Реализован общий Python pipeline, FastAPI с веб-страницей и Docker Compose.
Справочник редакции `2025-10-31`: 1220 leaf-тематик, 9 видов и 39 subtype-записей.
Версии и SHA-256 проверяются при загрузке.

Есть anchor-based preprocessing, отдельный `typeDecisionText`, hybrid BM25/FAISS,
быстрый/расширенный выбор вида и подтипа, ThemeSelector и Pydantic-валидация.
Расширенная ветка использует потоки для subtype; очереди фоновых задач нет.

OCR API/PDF — мультимодальная LLM через Hydra. PaddleOCR и lift сохраняются как
исследовательские альтернативы, их зависимости не входят в текущий runtime.
LangGraph, agent/tool calling, БД и обучение собственной модели отсутствуют.

Сохранённые результаты и размеры выборок: [evaluation](evaluation.md).
Максимумы отдельных запусков не означают такой же результат на новых данных.
Реальные исходники остаются локально вне отслеживания git. Для публичной проверки
есть существующий `seed_v1.json` и offline-тесты с внедрёнными callable/моками.

Ограничения: мало размеченных данных, пересечение few-shot с evaluation,
нестабильность ответов/latency провайдера, соседние subtype и лишние темы.
UI показывает таймер этапов и эвристическую уверенность; это не backend telemetry.
PDF endpoint синхронный, использует внешний API и сохраняет исходники/OCR локально.
Нет аутентификации, политики удаления артефактов, lock-файла и независимого holdout.

Проверка: `python -m pytest tests -m "not external"`.
Исторические заявления о числе тестов/coverage здесь не используются:
проверка зависит от текущих незакоммиченных изменений и среды.
