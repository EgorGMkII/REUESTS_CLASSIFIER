# Проверки подготовки репозитория

Проверено 3 октября 2026. Алгоритмы классификации сохранены; существующие тесты
согласованы с актуальными контрактами, порогами и prompts. В API-схему добавлено
поле themeSelection, чтобы текущая диагностика PDF-сервиса не отбрасывалась.

## Выполнено

- Существующие offline-тесты в `myenv`:
  `python -m pytest tests -p no:cacheprovider -m "not external"`.
  Результат: **101 passed**, coverage **85.38%** при обязательных 85%. Потребовался запуск
  вне sandbox: Windows блокировал временные каталоги pytest.
- Существующий API через FastAPI TestClient: `/health` и `/ready` возвращают 200
  с текущими готовыми индексами. Внешние LLM/embedding вызовы не выполнялись.
- 50 существующих seed-примеров валидируются штатным loader.
- SHA-256 справочника совпадает с index_report; индексы не перестраивались.
- `docker compose config --quiet` завершился с кодом 0.
- Перенесённые сборщики v2/v3: `py_compile` и существующий `--help` успешны.
- Ссылки документации существуют. JSON-отчёты парсятся; копии full-pipeline
  отчётов побайтно совпадают с исходными сохранёнными артефактами.
- `git diff --check` и staged-проверка не выявили whitespace errors.
- 47 приватных файлов исключены из индекса, все локальные копии сохранены.
  В текущем git-индексе нет реальных PDF/OCR/real-датасетов.
- В проверенных отслеживаемых текстовых файлах и старых коммитах не найдены
  ключи по шаблонам `sk-`/`sd-`; это проверка известных форматов, не гарантия
  отсутствия произвольного секрета. Реальные данные в старых коммитах остаются.

## Исправленные несовпадения тестов

Обновлены сценарии быстрого/расширенного пути под текущие пороги: helper для
расширенной ветки использует низкую уверенность, уверенный запрос информации
с слабой альтернативой проверяет быстрый путь. Subtype fixtures берут официальные
названия из каталога. Mock preprocessor явно задаёт отсутствующий typeDecisionText.
Параллельные subtype-вызовы больше не проверяются в порядке выполнения потоков.
Мок evaluation CLI принимает текущие аргументы и проверяет их передачу.
Prompt-тесты проверяют актуальные правила, включая 1–2 темы и исключительную третью.
Новые тесты/фреймворки/датасеты не добавлены.

Установлен указанный в requirements.txt pytest-cov; coverage gate 85% проходит.
В среде остаются warning requests/urllib3/charset-normalizer и deprecation warning FAISS.

Реальные LLM/PDF OCR проверки не выполнялись; в сессии нет `HYDRA_API_KEY`.

## Ограничения публичной демонстрации

Метрики — development-прогоны на 16–30 примерах с пересечением few-shot/evaluation.
Полные отчёты не сохраняли model/prompt manifest. Приватные датасеты не публикуются,
поэтому они не воспроизводятся из одного публичного checkout. Для запуска есть
безопасный существующий seed и справочники/индексы. История git не переписана;
публичность старых персональных данных остаётся отдельной нерешённой проблемой.
