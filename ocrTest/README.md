# Архив раннего OCR-прототипа

Код сохранён для сравнения подходов. Текущий API не импортирует этот пакет;
его отдельные зависимости не входят в runtime.
Основной OCR: [tools/ocr_lab](../tools/ocr_lab/README.md).

`appeals/`, `ocr_results/`, локальный `.env` и IDE-файлы остаются на диске,
но исключены из текущего публичного git-дерева. Старые коммиты содержат исходники;
исключение из текущего дерева не очищает историю.
